位於美國矽谷核心地帶的山景城（Mountain View），正研擬六年來首次針對停放於市區街道的休旅車（RV）及其他大型車輛實施更嚴格的管制措施。隨著房價高漲與生活成本危機加劇，越來越多民眾將大型車輛長期停放於公共街道，甚至衍生出俗稱「vanlording」（即車主將車輛長期停放或轉租牟利，類似將廂型車當成房產出租）的爭議現象，以及未與牽引車輛聯結的拖車亂象。這項新法規若正式通過，將賦予地方政府更大的執法權限，藉此改善市容、維護公共衛生及解決日益嚴峻的街頭停車亂象。然而，此舉也預料將引發關於遊民權益、社會福利及住房負擔能力的廣泛討論與爭議。
  • *六年來首次修法**：山景城睽違六年再度針對市內街道的休旅車與大型車輛研擬新規，顯示地方政府對街頭車宿問題的管理態度轉趨強硬。
  • *打擊「廂房出租」（Vanlording）與拖車亂象**：法規明確鎖定將車輛長期佔用道路甚至衍生商業牟利行為的現象，以及任意卸下、未與主車聯結而影響交通與市容的拖車。
  • *引發居住正義與治安的拔河**：這項政策反映了矽谷高房價下的社會困境，如何在維護社區生活品質與保障弱勢族群生存權之間取得平衡，將是當地政府面臨的重大考驗。
