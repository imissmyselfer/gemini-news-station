美國太空探索技術公司 SpaceX 在太空航行史上寫下全新篇章，成功在德州星港（Starbase）以發射塔的機械臂（綽號「筷子」Mechazilla），首次在空中精準夾住從軌道返回地球的「星艦」（Starship）超級重型推進器。這項創舉不僅是 SpaceX 可重複使用火箭技術的一大里程碑，更象徵著人類距離實現「快速且完全可重複使用」的太空運輸系統更近了一大步。過去，傳統火箭回收多數依賴海上或陸地平台垂直降落，而此次直接由發射塔回收的技術，省去了推進器上的傳統著陸支架，大幅減輕了火箭重量並提高結構效率。此項技術的成熟，將能顯著降低發射成本與時間，為未來載人登陸月球、甚至前往火星的長期深空探索計畫奠定堅實的基礎，也再次確立了 SpaceX 在全球商業航太領域難以撼動的領導地位。
  • *技術創新突破**：SpaceX 首次成功利用發射塔的機械臂在空中夾住重返大氣層的超級重型推進器，實現前所未有的回收方式。
  • *大幅降低成本**：省去傳統著陸支架的設計有效減輕火箭重量，並大幅縮短火箭發射與整備的循環時間，朝向「完全可重複使用」的目標邁進。
  • *深空探索里程碑**：此項技術的成功驗證，將直接加速未來 Artemis 登月計畫以及實現火星殖民等長期太空探索任務的進程。
